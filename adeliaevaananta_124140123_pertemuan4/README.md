## Deskripsi Program Tugas
- **tugas1_bmi.py**: menghitung BMI dari berat (kg) dan tinggi (m), lalu menentukan kategori (kurang, normal, berlebih, obesitas).
- **tugas2_nilai_mahasiswa.py**: mengolah data 5 mahasiswa (list of dictionary), menghitung nilai akhir berbobot 30% UTS + 40% UAS + 30% Tugas, menentukan grade A-E, menampilkan tabel, serta mahasiswa dengan nilai tertinggi dan terendah.
- **math_operations.py & main.py**: modul berisi fungsi luas/keliling (persegi, persegi panjang, lingkaran), konversi suhu, dan konstanta PI; `main.py` mengimpor dan menguji semua fungsi dengan 2 cara impor.

## Cara Menjalankan
Buka terminal di VS Code, masuk ke folder `tugas`, lalu jalankan:

```
python tugas1_bmi.py
python tugas2_nilai_mahasiswa.py
python main.py
```
